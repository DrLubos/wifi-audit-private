# Dashboard v2 design handoff

- `SPEC.md` – definitions, behaviour, data model, API and order of work.
  Read it first.
- `boards/` – one mock-up per screen (HTML + a `renderVals()` script with
  illustrative data). Read as text; they need the design tool's runtime to
  render. Board-to-route table: `SPEC.md` section 1.

Design approved by the developer on 2026-10-10. Changes to the design go
into `SPEC.md` (and a note in the commit), not silently into the code.
