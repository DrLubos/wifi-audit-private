Managed and friendly networks

Managed: a network you run. Its security is checked and every BSSID using its name that is not in the allowed list raises an alert (evil twin). Friendly: someone else's known, legitimate network (a neighbour, the next building). It is not checked and raises no events; it is only kept out of the unknown list.
